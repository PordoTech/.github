## 项目

| 仓库 | 说明 |
| --- | --- |
| [pordo](https://github.com/PordoTech/pordo) | 音乐、视频与漫画应用，提供 Windows、macOS 与功能有所不同的 Android 客户端 |
| [pordo-service](https://github.com/PordoTech/pordo-service) | 可自部署的独立内容源服务，提供漫画搜索、章节解析与源账号管理，预留影视扩展 |
| [remdia](https://github.com/PordoTech/remdia) | 不依赖 FFmpeg 的模块化媒体 SDK，通过独立组件组合系统媒体能力 |

## Projects

| Repo | Description |
| --- | --- |
| [pordo](https://github.com/PordoTech/pordo) | A music, video and comics app for Windows and macOS, with an Android companion for music and comics |
| [pordo-service](https://github.com/PordoTech/pordo-service) | A self-hosted content source service for comic search, chapter resolution and source account management, with video support planned |
| [remdia](https://github.com/PordoTech/remdia) | A modular media SDK that composes system media capabilities without FFmpeg |
